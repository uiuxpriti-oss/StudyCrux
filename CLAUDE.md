# StudyCrux — persistent product rules

## Pricing model (always enforce)
- Fixed price tiers exist ONLY for **Mock Tests**: Crux Sprint (15D), Prime Marathon (30D), Elite Quest (90D).
- **Live Courses**: custom/dynamic pricing per course, dynamic validity, multi-batch (Morning/Afternoon/Evening/Fast-Track), batch entity required.
- **Recorded Courses**: custom/dynamic pricing, dynamic validity, NO batch entity — direct profile access (incl. Lifetime).
- Students can hold multiple concurrent entitlements (several mock tiers + live batches + recorded passes at once).
- Never show a mock tier (Sprint/Marathon/Quest) as the plan of a Live-only or Recorded-only purchase — those show "Custom" / their own plan label.
- There is NO "subscription" concept in StudyCrux. Never use the word subscription — use entitlements, plans, validity, purchases, renewals.

## Design language
- Navy sidebar #0B1F3E, teal accent #0E9384, cream canvas #FAF9F5, Plus Jakarta Sans.
- Critical admin actions (refund, suspend, blacklist, batch change, trash) always use the two-step confirmation modal workflow.
